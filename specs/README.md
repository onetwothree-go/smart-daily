# specs/ — 规格驱动开发（SDD）目录

本目录存放项目的所有规格文档，按阶段组织：

```
specs/
├── README.md      ← 本文件：目录规范说明与版本总表
├── proposal.md    ← 需求规格（proposal）
├── design.md      ← 设计规格（design）
└── tasks.md       ← 任务拆解（tasks）
```

## 工作流程

1. **需求**：在 `specs/proposal.md` 中记录需求（当前单特性项目，单文件维护），描述要做什么、为什么、验收标准
2. **设计**：需求定稿后，在 `specs/design.md` 中编写技术设计
3. **任务**：设计定稿后，在 `specs/tasks.md` 中拆解为实现任务清单
4. **实现**：按任务清单开发，分支规范见根目录 [BRANCHING.md](../BRANCHING.md)

## 命名约定

- 文件名使用小写英文与连字符：`user-login.md`
- 每个规格文档头部包含：状态（草案/评审中/已定稿）、作者、日期
- 当前项目为单特性，三份规范均为顶层单文件；若后续拆分多特性，再按上述命名约定新建子目录。

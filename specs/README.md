# specs/ — 规格驱动开发（SDD）目录

本目录存放项目的所有规格文档，按阶段组织：

```
specs/
├── README.md          ← 本文件：目录规范说明
├── requirements/      ← 需求规格（每个特性一个 .md 文件）
├── design/            ← 设计规格（架构、接口、数据模型）
└── tasks/             ← 任务拆解（实现计划）
```

## 工作流程

1. **需求**：在 `requirements/` 下新建 `<特性名>.md`，描述要做什么、为什么、验收标准
2. **设计**：需求评审通过后，在 `design/` 下编写技术设计文档
3. **任务**：设计定稿后，在 `tasks/` 下拆解为实现任务清单
4. **实现**：按任务清单开发，分支规范见根目录 [BRANCHING.md](../BRANCHING.md)

## 命名约定

- 文件名使用小写英文与连字符：`user-login.md`
- 每个规格文档头部包含：状态（草案/评审中/已定稿）、作者、日期

## 五、规范践行结论（可直接用于总结报告第 2 章引用）

本项目四周始终坚持"规格先行、小步提交、证据留痕"：v1 建立 proposal/design/tasks 三层规格与 ADR 决策记录，v2 以**差异版**方式继承而非复制（G2 零复制 0 命中），每周产出均有可复跑命令与提交号支撑；变更涟漪按 proposal→design→tasks→代码→回归自上而下同步，任何一处未同步即记为缺陷（DEF-05 / DEF-10 已实证处理）。规范守护以 CI 三道门（lint / format / 覆盖率）+ 人工一致性检查 + 缺陷登记三层兜底；"改代码未改规范"的自动检查当前仍缺、已如实登记为待组内裁定的补强项，不虚报全绿。签字栏与状态列严格按责任人归属，AI 不代签代判。

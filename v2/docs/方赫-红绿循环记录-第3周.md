## 使用说明

- 编号与提交保持一致：`TK-V2-xxx`。
- 「红」必须贴出真实的失败输出（模块不存在 / N failed），证明先写测试后写实现。
- 「绿」记 commit 号与 message；「重构」单独一条 commit（若组内约定 refactor 不入规范格式，用 fix/test 类并对齐）。
- 每条末尾注明 AI 参与度，并确认当天 `docs/ai-usage-log.md` 已补记录。

## §2 演示脚本（逐步可复制）

> 以下命令在 PowerShell 中，`cd D:\SDD-project\smart-daily-dev\v2` 后执行。

**第 0 步 · 准备环境（首次）**

```
uv sync --dev
```

**第 1 步 · 跑无凭证演示（核心一步）**

```
$env:DB_PATH = "./data/demo.db"
python -m smart_daily_v2.cli --mock --no-notify --day 2026-11-18
echo "exit=$LASTEXITCODE"
```

- `--mock`：用占位数据（含考勤条目），不要任何凭证。
- `--no-notify`：只生成日报、不推送，避免外部副作用。
- `--day 2026-11-18`：**必须指定夹具日期**——mock 考勤条目固定在这一天，不指定则当天无考勤行可看。
- 退出码应为 **0**。
- 注意：`--mock` 与 `--source` 是互斥参数组，**不要同时传**（见 §4 边界②）。

**第 2 步 · 看历史日报元数据**

```
python -m smart_daily_v2.cli --list
```

**第 3 步 · 验证落库日报里有考勤行**（演示"真出结果"）

```
python -c "import sqlite3; c=sqlite3.connect('./data/demo.db'); rows=c.execute(\"select member,content from daily_reports where report_date='2026-11-18'\").fetchall(); print('rows:',len(rows)); [print(m,'| 考勤行:',t.count('考勤')) for m,t in rows]"
```

**预期现象**：4 位成员各一份日报；**甲、丙**各有 2 处 `考勤`（badge + 表格行渲染），**乙、丁**为 0 —— 无考勤的成员不出现考勤条目（C8 语义）。

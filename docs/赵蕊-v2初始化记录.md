## 方案变更：长驻分支 → 目录隔离（2026-11-16 11:30）

**触发原因**：按 proposal S1 / I2，日报采集只读 `main` 默认分支，`dev`/feature 上未合并的提交不进日报。若 v2 放在独立长驻分支，本周开发在全链路（实时提醒触发分支、日报采集范围）里都不可见；而为此去改采集口径，要连带修改 S1、I2、C1 计数口径、design §3 契约与两份报告，正是课程第 24 页明令按缺陷计的「规范与实现不一致」。改放 dev 的 `v2/` 目录后，提交直接落在 dev 上，**不需要变更任何采集口径**。

## 3. 发现的一个真实缺陷（已核实，未擅自修改）

README「快速开始」第 3 步给出的命令：

```
$ uv run smart-daily --mock --day 2026-11-02
ImportError: cannot import name 'main' from 'smart_daily' (src\smart_daily\__init__.py)
```

**原因**：`pyproject.toml` 的 `[project.scripts]` 写的是 `smart-daily = "smart_daily:main"`，但 `main()` 实际定义在 `smart_daily.cli`（`src/smart_daily/cli.py:52`），包顶层 `__init__.py` 并未导出它。

**建议修复**（一行，留待评审后由相应负责人改）：

```toml
[project.scripts]
smart-daily = "smart_daily.cli:main"
```

在修复前，所有功能均可通过 README 列出的另一条等价命令使用：

```
uv run python -m smart_daily.cli --mock --day 2026-11-02
```

本记录步骤 4–6 均采用模块方式调用，不受该缺陷影响。

## 一、评价维度与方法

分工单指定四个维度：**上手门槛、配置步骤数、要不要命令行、有没有免费额度**；补充两个观察项：数据源自动化程度、推送是否内置。

方法：官方文档 / 仓库 README 逐条核对，与组内于悦《同类竞品调研记录》的**亲手实操截图（15 张）及全量源码阅读**交叉验证。
**每条结论至少两个独立来源，URL 见 §四**（官网/官方 README + 独立实测/README）。

> 诚实性说明：于悦那份是**技术观察**（功能模块、UI 与交互、核心流程），本份是**易用性评价**，不照抄其技术结论；步骤数是按官方文档可数出的操作步数计，**非本人本机安装计时**，未亲自安装的项目在表中标注「据文档」。

## 二、三方案易用性对比

| 维度 | Aiscribe（开源 AI 工具） | gh-daily-report（开源 CLI） | Teambition AI 智能周报（商业 SaaS） | 对照：本组 smart-daily |
|---|---|---|---|---|
| 形态 | 本机 Python 工具 + 本地 Web 引导页 | 纯命令行脚本（依赖 gh CLI + jq） | 网页/钉钉客户端 SaaS | GitHub Actions + Python 脚本 |
| 上手门槛 | **低**（四步图形向导点选），但安装与启动需敲 2 次命令 | **中**（面向开发者，全程命令行，无 GUI） | **最低**（开箱即用，纯图形界面） | **高**（需 git / uv / gh 与仓库权限） |
| 配置步骤数（据文档计） | **6 步**：clone ① → 启动 `aireport ui` ② → 向导四步（选数据源③／定时间窗④／挑素材⑤／定排版输出⑥） | **3 步**：装 gh + jq ① → `gh auth login` ② → 跑脚本 ③ | **2 步**：建项目/套模板 ① → 开启 AI 智能周报 ② | **约 10 步**：5 个环境变量 + 2 条 Secrets + 机器人 3 项设置 + 显示名映射 |
| 要不要命令行 | **要，但只 2 次**（clone、启动 UI），之后零命令行 | **全程要** | **不要** | **全程要** |
| 免费额度 | **全免费**（MIT 开源、本地运行、零 pip 依赖）；AI 归纳若接 DeepSeek 需自备 Key，**可关闭退模板** | **全免费**（开源脚本；受 GitHub API 速率限制） | **基础版 10 人以内 ¥0/人/年免费**；深度分析/AI 周报类高级能力在**企业版 ¥399/人/年、旗舰版 ¥699/人/年**（10 人起售）之后 | **全免费**（开源 + 国产模型免费额度） |
| 数据源接入 | 本机 17 源自动采集，无需配置 | GitHub 单源，`gh` 实时查询 | 仅自家任务系统，手工/看板流转 | GitHub + 飞书 + 群消息三源自动采集 |
| 推送是否内置 | ✅ 钉钉日报 API（可选配置） | ❌ 输出到剪贴板，手动贴 Slack | ✅ 保存为钉钉文档分享 | ✅ 飞书群机器人（实时 + 22:00 汇总） |

## 三、结论（每条标注两个独立来源）

| # | 结论 | 来源 |
|---|---|---|
| C1 | 命令行门槛呈三档：Teambition 0 次 < Aiscribe 2 次（仅安装/启动）< gh-daily-report 全程。对非开发者最友好的是商业 SaaS，开源方案里 Aiscribe 的本地 Web 向导明显降低了门槛 | A1 + A3 ／ B1 + B2 ／ C1 + C4 |
| C2 | 免费额度不等于「AI 能力免费」：两个开源方案全部功能免费；Teambition 基础版虽 10 人免费，但 AI 智能周报、深度分析、批量导出等属付费版本，学生小组用免费版拿不到核心 AI 报告能力 | A1 + B1 ／ C2 + C3 |
| C3 | 配置步骤数与可配置性正相关：Teambition 2 步但黑盒不可配、数据锁在自家生态；Aiscribe 6 步换来 17 个数据源可插拔；gh-daily-report 3 步但只采 GitHub、无自动推送 | A1 + A3 ／ B1 + B3 ／ C1 + C4 |
| C4 | 对本项目的启示：**上手门槛是我们当前最弱的一项**（约 10 步配置、全程命令行）。可借鉴 Aiscribe 的「本地 Web 引导页」把环境变量/映射配置图形化，借鉴 Teambition 的模板一键复用降低首次使用成本；但保留多源采集与飞书推送这两个三者都没覆盖的差异点 | A1 + A3 ／ C1 + C4 ／ 本仓库 `README.md` |

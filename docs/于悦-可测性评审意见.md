### 评审口径（三档判定，沿用任务指令定义）

- **可测** = 输入条件、观测输出、阈值或状态三要素齐备，照着就能测。
- **有条件可测** = 缺一要素，但补上就能测；缺什么写清楚。
- **不可测** = 表述模糊或依赖无法构造的条件；给改写建议。
- **补充裁定（C7 / G4 适用口径）**：若所缺要素需要开发新增系统输出（如补时间戳字段）才能获得 → 判「不可测」，待该输出落地后重判；若只影响标准的一部分（而非整条）→ 整条降为「有条件可测」（如 G4 仅送达时间缺时间戳、骨架部分仍可测）。

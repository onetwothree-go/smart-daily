# 同类 Agentic CLI 方案易用性对比测试记录

> 测试人：方赫（测试工程师）
> 测试日期：2026-11-03 ~ 2026-11-09
> 测试环境：Windows 11 / 64 位，网络环境含代理与直连两种

## 一、测试目的

为小组 proposal 的工具选型提供依据：在课程约束（Agentic CLI、可接入国产模型 API、成本可控）下，对比候选 CLI 工具的易用性，得出选型结论。

## 二、测试对象与方法

| 维度 | 说明 |
|---|---|
| 对象 | Claude Code v2.1.316/318（后端分别接智谱 glm-4.6、DeepSeek-V3.2）、Codex CLI 0.166.0（未登录，仅安装验证） |
| 方法 | 统一任务清单实测：①安装到首次成功对话 ②生成最小 Python 工程 ③修改既有文件 ④导出会话记录 ⑤技能/扩展安装 |
| 指标 | 各环节耗时（分钟）、卡点次数、是否需要代理、失败重试次数 |

## 三、实测记录

| 测试项 | Claude Code + glm-4.6 | Claude Code + DeepSeek-V3.2 | Codex CLI |
|---|---|---|---|
| 安装耗时 | npm 全局安装 ≈2 分钟 | 无需重装，改环境变量 ≈1 分钟 | npm 安装 ≈2 分钟 |
| 登录/配置卡点 | ⚠️ 官方订阅登录不可用（403 地区限制 + 需付费订阅），改走国产 API 兼容端点解决 | ✅ 兼容端点即插即用 | ⚠️ 需 ChatGPT 订阅，未通过 |
| 首次对话成功率 | ✅ 通过 | ✅ 通过（实测问答与代码生成正常） | 未测（登录受阻） |
| 生成最小工程 | ✅ 通过，产物可直接 uv run | ✅ 通过 | 未测 |
| 会话导出 | ✅ /export 可用 | ✅ /export 可用 | — |
| 技能库安装 | ✅ Superpowers v7.0.2 安装成功、可列出 15 个技能 | 同左（工具层一致） | 官方市场可装（未验证） |
| 网络要求 | ❌ 需代理（浏览器授权环节） | ✅ 国内直连 | ❌ 需代理 |

## 四、结论（供 proposal 引用）

1. **选型：Claude Code CLI + 国产模型兼容端点（DeepSeek-V3.2，硅基流动）**——工具形态满足课程要求，国内直连、成本接近零
2. 关键易用性差异在"登录配置"环节：官方订阅路径对国内学生不可行，Anthropic 兼容端点是必选项
3. 遗留风险：CLI 对第三方模型名给出"unrecognized"警告（不影响功能）；模型代码能力弱于官方 Claude Sonnet，复杂重构任务需人工多轮引导

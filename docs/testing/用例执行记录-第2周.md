## 一、记录格式（每条用例必须记满 8 个字段）

| 字段 | 填写要求 |
|---|---|
| 用例编号 | G1 / G3 / G4 / G5 / C1–C5 / C7–C10，与核对表一致 |

| 日期 | YYYY-MM-DD，**当天记录，不得事后补写** |
